# Daeyeo
2023년 ICC 연계 창업경진대회에서 시제품으로 활용한 **공공시설·개인 물품 통합 대여 플랫폼** 입니다.
Spring Boot를 기반으로 공공시설 및 개인 소유 공간과 물품을 사용자 간에 대여할 수 있는 웹 애플리케이션 프로토타입을 구현했습니다.

## 프로젝트 소개
사용자는 자신이 소유한 공간이나 물품을 플랫폼에 등록할 수 있으며, 대여를 원하는 사용자는 등록된 상품의 대여 가능 기간과 시간을 확인하고 원하는 시간대를 선택하여 대여할 수 있습니다.

공공시설 관리자의 경우 관리 중인 시설의 공간이나 물품을 등록하여 대여할 수 있도록 하여, **공공시설과 개인 소유 자원의 유휴 공간 및 물품을 효율적으로 활용하는 것을 목표로 했습니다.**
